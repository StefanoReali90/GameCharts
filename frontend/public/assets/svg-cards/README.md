SVG-Cards artwork by David Bellot, from the fork maintained by Huub de Beer:
https://github.com/htdebeer/SVG-cards

The unmodified SVG sprite, 2x PNG renders, AUTHORS file, and LGPL-2.1 license
are included here. The frontend displays the PNG cards in player avatars; the
SVG sprite remains available for other card views.

png/joker_custom.png is a user-provided replacement for the displayed joker.
